# Echo · 替你记着

手机网页：https://yancd366.github.io/echo/

收下文字、链接、截图、文件和灵感，在日／周／月回顾中重新发现，并按自己的节奏行动。

0.3 支持专题、行动步骤与计划、场景推荐、PDF／文本提取、录音原件、ICS 导出、备份和 Android 分享目标。AI 理解、来源问答、周期总结、语义找回和转写可在 App 设置连接模型后启用，默认不开启付费调用。

本仓库仅含静态网页代码、图标、演示内容与 PDF.js 浏览器组件及其许可证。用户记录和原始附件保存在用户自己的浏览器；不含用户备份、截图或供应商密钥。

目前没有跨设备同步、iPhone 原生分享扩展、关页后定时生成与推送。界面有完整能力与限制说明。
